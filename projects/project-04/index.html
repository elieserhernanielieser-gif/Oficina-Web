Artigo com tipografia cuidada

Letra capital, aspas decorativas, resumo cortado e seleção com cor própria.

O bom design começa pelo texto. Uma letra capital e um espaçamento bem pensado mudam a forma como o leitor sente a página.

Escreve para quem lê, e não para quem escreve.

Este resumo é bem mais longo do que cabe no espaço. O CSS corta o texto ao fim da terceira linha e acrescenta reticências sozinho, sem ser preciso contar palavras. Experimenta mudar o número de linhas e ver o que acontece com o texto quando o conteúdo excede o espaço disponível para apresentação.

Seleciona este texto com o rato para veres a cor de seleção personalizada.
